# Agent Skills の棚卸し

対象は発火条件、手順の書き方、同梱リソース、インストール後のパス。

| スキル | 指摘 | 対応 |
| --- | --- | --- |
| `estat-file-search` | レシピにリポジトリルート前提のパスがあり、入口からレシピを探しにくい | 用途別リンクと、各スキルのディレクトリを基準にしたパスを記載 |
| `estat-api-data-search` | 発火条件と後続のメタデータ・プレビューレシピの関係が曖昧 | 入口をテーブルID探索に揃え、確認後のレシピをリンク |
| `paper-excel-to-table` | 本文とサブエージェントで手順が重複し、存在しない設計文書への参照があった | 前提を frontmatter に記載し、観察・裁断・検証の手順をスキル内で共有 |

e-Stat の探索手法、API の挙動および同梱する統計コード一覧は、今回の棚卸しの対象外。

配布時の形式チェックには `gh skill publish --dry-run` を使える。3スキルの検出、フォルダ名との一致、frontmatter の必須項目を確認できる。
